# 以时间线为轴

> 把所有东西都变成时间轴上的一个点，然后能翻回去看。

这是 LifeTrack 的唯一内核。不是「有很多功能、每个功能各存各的」，而是**只有一条时间轴**，随记、待办、目标、里程碑、项目、周报 / 月报 / 年度总结，全都是这条轴上的投影。你做的每一个动作，最终都会落到时间上，成为可以回放的一格。

---

## 一、所有功能都是时间轴的投影

不搞独立模块。凡是「另起一个东西、自己管自己」的设计都不要。

| 概念 | 在时间轴上是什么 |
| --- | --- |
| 随记 | 时间点上的**正文**，时间轴的基本单位 |
| 里程碑 | 被标记为「重要」的**任意时间点**（随记 / 待办 / 报告 / 目标进展皆可） |
| 待办 | 状态每变一次，就在轴上落一个点 |
| 目标 / 项目 | 一段时间内相关点的**聚合视图**，不是装数据的容器 |
| 周报 / 月报 / 年度总结 | 同一条时间轴，只是**缩放档位**不同 |
| 番茄钟 | 一段专注时长的**落点**，记录“这段时间做了什么” |

一句话：**随记是实体，其余皆视图。** 项目是「签」，用来给随记打标记；不是仓库，不把数据锁进去。翻回任意一刻，都能看到当时发生了什么、和哪些项目有关。

---

## 二、随记（原日志）

- **不限制每天只能写一篇**，想写几条写几条。
- 叫「随记」而不是「日志」：减少「今天已经写过了」的心理负担。它是随手记，不是打卡作业。
- **时间轴按天折叠**：默认只显示日期和条数，点开才展开当天所有记录。看历史时先看到「节奏」，需要时再钻进「细节」。
- **类型固定，标签自由**：
  - 类型管**行为**——它决定这条记录怎么被处理、归到哪个统计口径，是有限、稳定的集合；
  - 标签管**内容**——它随你心情和语境自由生长，是用来日后捞回来的钩子。

  行为要可预期，所以类型要收；表达要灵活，所以标签要放。

---

## 三、里程碑

**里程碑不是某种数据的专属字段,而是一个「标记动作」。** 时间轴上任意一格——一条随记、一次待办流转、一份周报 / 月报 / 年度总结、目标的某一次进展——都可以被标记为里程碑。它不专属于随记。

### 标记发生在「现在」,指向「过去」

这一点很重要:标记本身也是一条时间轴上的点。

> 2022 年我做了某件事,当时没什么感觉;2026 年回首,才认定它是我人生的里程碑。

所以要落两个点,缺一不可:

- **被标记的那一格**:仍然停在 2022 年原地,只是被高亮出来。
- **标记这个动作**:发生在 2026 年,内容写着「把 2022 年某天的某事,标记为里程碑」,并能跳回原记录。

撤销标记同理,再落一个点(「取消里程碑」)。**认定与收回都留痕**,回放时能看到「我哪天把它当回事、哪天又改了主意」——这和待办的状态流转是同一套哲学:标记动作本身就是一条决策轨迹。

### 高亮是「派生」出来的,不是复制

里程碑不复制内容,只存一个指向原记录的引用。某一格到底算不算里程碑,是顺着「谁被标记、又有没有被撤销」现算出来的:

- 在时间轴上**高亮显示**，一眼能从流水里跳出来;
- **不参与折叠,而是被“拎”到最近的可折叠层**——时间轴是年→月→日三级,谁被折起,里程碑就上浮到谁的头下:展开到当日则就地高亮;收起某一天则留在当日头下;连月都收起,该月的里程碑上浮到月头;整年收起,则整年的里程碑直接列在年头下。

这样无论怎么折叠,里程碑都不会消失。收起全部时,一眼扫过去的就是历年人生大事——**这正是要“翻回去看”时最想看到的东西。**

它不需要单独一张「里程碑表」。被一条有效的标记引用,它就是里程碑;标记撤销,它退回成普通一格。

---

## 四、待办

待办的状态流转本身就是一条**决策轨迹**，所以每一次状态变化都要写入时间轴：

| 动作 | 写入时间轴 | 含义 |
| --- | --- | --- |
| 创建 | 落一个点 | 这件事进入我的视野 |
| 确认 | 落一个点 | 我决定认真做它 |
| 放弃 | 落一个点 | 我决定不做了（这也是决策，不是失败） |
| 完成 | 落一个点 | 这件事闭环了 |

四个状态 `待确认 / 进行中 / 完成 / 放弃` 的流转，回放起来就是「我在哪天、对哪件事、做了什么决定」。待办因此不只是待办清单，它是**留在时间轴上的一串判断**。

---

## 五、翻回去看

所有投影最终服务于一个动作：**回放**。

按天折叠看节奏，展开看细节，里程碑和状态流转的高亮点把你拽回那些真正重要的时刻。周 / 月 / 年不是别的本子的摘要，是同一条轴拉远之后的形状。

时间线为轴，其余皆投影。

---

## 六、数据观

- **本地即全部**：数据存在一个 SQLite 文件里，不联网、不上传、不账号绑定。带走那个文件，便是带走了自己的记录。
- **落笔无负担**：一句随记、一个番茄钟、一次状态流转，都是有效的记录。不必酝酿，想起即写下。
- **只增不减**：时间线是 append-only 的流水。事件一旦写入就不修改不删除（撤销里程碑也只是再落一个点），保证「翻回去」永远看得到当时真实的状态。
- **先做后记**：动作发生的那一刻只负责「做」（计时、完成任务、记一句话），「它意味着什么」留到回放时再认定。降低当下负担，给意义以时间。
